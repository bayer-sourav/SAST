   **Critical Question**: Does `response.getWriter().format(String format, Object... args)` perform automatic escaping?
   In standard JSP/JSTL contexts, EL expressions might escape. But this is plain Java servlet code calling `HttpServletResponse.getWriter()`.
   The `Writer.format` method (introduced in Java 11/12?) formats arguments according to the format string. It generally inserts the string representation of objects directly. It does **not** automatically HTML-escape strings unless the format specifier implies it (which `%s` usually does not for Writer, unlike `printf`). Actually, `Formatter` methods typically convert objects to their string representations. If the object is a String containing `<script>`, it writes `<script>`.
   
   Even if we don't know the exact Java version behavior of `format` regarding escaping, the general consensus for SAST is that passing user-controlled data into a `PrintWriter` or `Response.getWriter()` via formatting methods is considered a potential XSS vector unless explicit escaping is performed.
