        *   This rule typically flags cases where user input is used to construct a network destination (URL, socket, etc.) without sufficient validation against Internal/Private IPs.

                *   Crucially, `InetAddress.isSiteLocalAddress()` in Java primarily targets IPv6 Unique Local Addresses. It does *not* reliably detect IPv4 private addresses (Class A, B, C private ranges like 10.x.x.x, 192.168.x.x).
