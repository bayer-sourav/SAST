5. If ALL addresses pass the check (none are blocked), the loop completes
6. Then `URI.create("http://" + host)` creates the URI using the original `host` variable
7. The HTTP client sends a request to this URI

The sink is at line 32: `java.net.URI.create("http://" + host)`

What is the resolved value of `host` at this point?

- An attacker could supply a malicious domain like `evil.com` that resolves to legitimate IPs while also having a CNAME pointing elsewhere, potentially bypassing the basic checks

This represents a classic SSRF vulnerability—the application accepts arbitrary hostnames, performs minimal validation on resolved addresses, yet constructs requests using the original unvalidated input.
